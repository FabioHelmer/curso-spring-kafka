# Curso Spring Boot + Kafka

Projeto desenvolvido durante os estudos do curso de Spring Boot com Apache Kafka da Udemy.

## Tecnologias utilizadas

- Java 21
- Spring Boot
- Spring Data JPA
- Apache Kafka
- PostgreSQL
- Maven
- Lombok

## Objetivo

O objetivo deste projeto é praticar conceitos de microsserviços e mensageria utilizando Kafka com Spring Boot.

## Funcionalidades

- Cadastro de pedidos
- Integração com Kafka
- Persistência com PostgreSQL
- Comunicação entre serviços
- Validação de dados
- Uso de DTOs e mapeamento

## Como executar

### Clonar o projeto

```bash
git clone https://github.com/FabioHelmer/curso-spring-kafka
```

### Subir dependências

Necessário possuir:
- Java 21
- Maven
- PostgreSQL
- Kafka

### Executar aplicação

```bash
mvn spring-boot:run
```
